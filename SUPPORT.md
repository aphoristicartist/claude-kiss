# Support

- Use [GitHub Discussions](https://github.com/aphoristicartist/claude-kiss/discussions) for
  setup questions, usage help, and early ideas.
- Use [GitHub Issues](https://github.com/aphoristicartist/claude-kiss/issues) for reproducible
  bugs and scoped feature proposals.
- Use the private **Report a vulnerability** form in the Security tab for security concerns.

Include the Claude KISS version, Claude Code version, operating system, installation method,
and the smallest reproduction that demonstrates the problem. Remove credentials, private
source, and personal paths before posting logs.

Questions about Claude Code accounts, billing, model availability, or upstream CLI behavior
belong with Anthropic support unless Claude KISS changes that behavior unexpectedly.
